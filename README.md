# Retail Sales Cleaning & Analysis

Data cleaning e analisi esplorativa su un dataset retail intenzionalmente "sporco", condotti in Power Query e Power BI.

Il racconto completo del progetto — metodo, domande esplorative, risultati e limiti — è sul case study Notion: [Visita il portfolio completo](https://tinyurl.com/ruth-data-analytics)

## Contenuto del repository

- retail.dirty.xlsx-File Excel con le query Power Query: pulizia del dataset (`retail_store_sales`), controllo valori nulli su Discount Applied, tabelle di lookup, primo raggruppamento esplorativo per categoria (`EXPLORE_revenue_category`).
- retail-sales-cleaning_PowerBI.pbix — Report Power BI con l'esplorazione approfondita: fatturato e scontrino medio per categoria, andamento mensile del fatturato, confronto sull'effetto di Discount Applied.
- Cleaning_Log_Progetto2.pdf — Log dettagliato di tutte le trasformazioni di pulizia applicate, campo per campo.

## Dataset

[Retail Store Sales: Dirty for Data Cleaning](www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning) — dataset transazionale retail, scelto per la sua dirtiness intenzionale, utile a esercitare un processo di cleaning tracciabile.

## In sintesi

Il dataset si è rivelato avere una distribuzione sostanzialmente uniforme tra categorie, senza stagionalità né effetto misurabile dello sconto sul valore delle transazioni — un risultato "negativo" ma verificato con rigore, e documentato come tale. Dettagli completi nel case study linkato sopra.
